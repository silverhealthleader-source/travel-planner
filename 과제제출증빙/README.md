# A1-2 국내 여행 추천 프로그램 — 과제 제출 증빙

이 폴더에는 `travel-planner` 프로젝트의 개발 과정과 실행 결과를 확인할 수 있는 화면 캡처가 들어 있습니다.

> 보안 안내: 실제 Gemini API 키와 Kakao REST API 키는 포함하지 않았습니다. API 키는 `.env` 파일에서 관리하며, `.gitignore`를 통해 Git 업로드 대상에서 제외했습니다.

## 1. 최종 구현 결과

- `-date YYYY-MM-DD` 형식의 여행 날짜 입력 및 검증
- Google Gemini API를 이용한 국내 여행지 추천
- Pydantic 기반 구조화 JSON 검증
- Gemini 응답 검증 실패 시 최대 1회 재요청
- 추천 도시를 기준으로 Kakao Local API 음식점 5곳 검색
- 결과를 UTF-8 JSON 및 Markdown 파일로 저장
- 잘못된 날짜 형식, 존재하지 않는 날짜, 필수 인수 누락 차단
- GitHub `main` 브랜치 최종 업로드 완료

## 6. 최종 보안 확인

- 실제 API 키가 포함된 `.env` 파일은 Git에 등록하지 않음
- `.venv` 및 백업 파일은 Git에서 제외
- API 키 관련 화면은 값이 노출되지 않도록 마스킹하거나 설정 여부만 표시
- 소스 코드, README, 결과 JSON 및 Markdown에는 실제 API 키가 없음
